# Gravity_Eater

## 1. 프로젝트 개요
- 장르 : 실시간 멀티플레이어, io 서바이벌
- 플랫폼 : PC / Windows
- 핵심기술 : 유니티, 포톤, 파이어베이스
- 개발기간 : 2026.01.12~ 2026.01.30

## 2. 게임 컨셉 및 특징
### 2.1 게임 소개
- 광활한 우주를 배경으로 소행성과 행성을 흡수하며 성장하는 블랙홀 경쟁 게임입니다.
- Slither.io의 직관적인 게임성과 블랙홀 테마를 결합했습니다.

### 2.2 핵심 재미 요소 (Key Selling Points)
- **성장의 희열** : 작은 먼지에서 거대한 블랙홀로 변하는 시각적 피드백.
- **긴장감 넘치는 경쟁** :  한 번의 실수로 모든 것을 잃을 수 있는 하이 리스크-하이 리턴 구조.
- **명예의 전당** : 실시간 랭킹 시스템을 통한 성취감 제공.

## 3. 게임 메카닉스 (Mechanics)
### 3.1 조작 및 이동
- **입력** : Mouse Position 기반 방향 이동.
- **카메라** : 블랙홀 크기에 비례하여 자동으로 줌아웃(Orthographic Size 조절).

### 3.2 성장 및 충돌 규칙
- **흡수 대상** : 우주먼지(1점) < 소행성(5점) < 행성(20점) < 별(100점).
- **사망 판정** : 나보다 큰 블랙홀의 이벤트 호라이즌(몸체) 영역에 내 중심점이 닿을 시 사망.
- **전리품** : 사망 시 누적 점수의 50%가 먹이 아이템으로 해당 위치에 생성.

## 4. 시스템 구조 (System Architecture)
### 4.1 네트워크 (Photon)
- **Matchmaking** : 로비 진입 시 자동으로 빈 방 참여 혹은 생성.
- **Sync** : 위치, 회전, 스케일 및 먹이 아이템의 활성화 상태 동기화.

### 4.2 데이터 관리 (Firebase)
- **인증** : 닉네임 기반 익명 로그인.
- **DB** : 실시간 리더보드 데이터 저장 및 불러오기 (Score, Nickname).

## 5. 개발 일정 (Timeline)
- 1주차 : 핵심 기능 구현 (이동, 흡수, 포톤 동기화)
- 2주차 : 시스템 고도화 ( Firebase연동, 랭킹, UI, 이펙트)
- 3주차 : 디버그 및 폴리싱
